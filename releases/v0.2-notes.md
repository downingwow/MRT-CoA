# MRT-CoA v0.2 diagnostic build

Local test archive: `MRT-CoA-v0.2-class-spec-diagnostics.zip` (not yet uploaded to GitHub).

Changes:
- Query `C_CharacterAdvancement.GetActiveChrSpec` and `C_ClassInfo.GetSpecInfoByID` for parent class and active specialization.
- Query `C_ClassInfo.GetAllSpecs` for current class specialization list.
- Avoid overriding global `GetClassInfo`.
- `/mrtcoa` prints raw `UnitClass`, resolved parent class, active spec, and discovered spec count.

Known limitations: no complete 21-class registry, no custom cooldown integration, no visual fixes. Test on Primalist / Wildwalker and report the `/mrtcoa` output.
