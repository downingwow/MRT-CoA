# MRT-CoA v0.5

Expanded class discovery build based on verified Primalist/Wildwalker diagnostics.

- Preserves verified Primalist specs (Wildwalker 59, Grovekeeper 58, Mountain King 60, Geomancy 95).
- Adds automatic party/raid class-token observation.
- Adds `/mrtcoaroster` to inspect observed group members.
- Adds **optional experimental** `/mrtcoascan` to query spec IDs 1–150. This invokes client-native APIs and could be unstable; avoid if concerned about client crashes.
- Keeps existing MRT cooldown tables unchanged; full 21-class UI integration is pending.

The complete source archive has not yet been imported into GitHub. Do not use the repository alone as an installable addon.
