# MRT-CoA development

Target: Ascension Conquest Reborn (WoW 3.3.5a).

## v0.1 class discovery

The local v0.1 ZIP includes an experimental `MRT/CoAClasses.lua` class registry and `/mrtcoa` diagnostic command. The full addon source has **not yet been imported into this repository**. Do not install this repository as a complete addon.

## Priorities

1. Verify all 21 custom classes through in-game diagnostics.
2. Adapt MRT class filters, icons, assignments, and inspections.
3. Cross-reference Ascension addon Lua and CoACooldownManager for custom cooldown spell IDs.
4. Address visual problems after class support.

Keep MRT independent of DBM-CoA and preserve original addon features where possible.
